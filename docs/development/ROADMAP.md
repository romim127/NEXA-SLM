# Roadmap
Arquitectura completa desde el minuto cero; implementación por etapas.
| Fase | Entregable | Gate |
|---|---|---|
| 00 | Foundation, gobernanza y requisitos | Árbol y contratos documentados |
| 01 | Knowledge Base y Lexicon | Esquemas, fuentes, revisión |
| 02 | Keyword Engine | Spans y sinónimos probados |
| 03 | Semantic Core y Universal IR | Ambigüedad y tipado |
| 04 | Compatibility y Syntax Engine | Dependencias y adaptadores |
| 05 | Explain, Validation y Security | Explicaciones y estados separados |
| 06 | FastAPI local y React UX | Flujo integral con filtros, copiar y lexicon |
| 07 | Benchmark y Local AI | Modelo seleccionado por evidencia, fallback y RAG |
| 08 | Packaging y ScriptGuard | Offline, integridad y aislamiento |
| 09 | Dataset y LoRA/QLoRA | Evaluación reproducible |
| 10 | Persistencia y distribución | Pruebas multiplataforma, privacidad, release |
Cada gate requiere evidencia; no se declara fase aprobada por silencio. Véanse IMPLEMENTATION_STATUS.md y PENDING_TASKS.md.
