# Security boundaries
Loopback only by default; explicit origin allowlist, request limits, no telemetry by default. Treat model output, prompts and user text as untrusted. Validate IR against allowlisted catalog and parameter types. No shell execution, eval, arbitrary imports or automatic code execution. Compiler validation, when implemented, must use isolated bounded processes with no network and no access to user files. Prevent path traversal and unsafe template interpolation. Model/runtime distribution requires pinned provenance, licenses, SHA-256, verified manifests and explicit updates. Never claim static analysis guarantees safety. ScriptGuard integration planned. History opt-in; no automatic training on user data.
