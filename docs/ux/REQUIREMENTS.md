# Mandatory product requirements
1. Free-text Spanish intent, with example selector as secondary affordance.
2. Highlight detected keyword spans, actions, objects, parameters and context.
3. Show resolved intent, ambiguity and supported implementation count.
4. Filterable language/technology cards, syntax highlighting, copy button, explanations and dependencies.
5. Comparative dictionary: reserved words, operators, symbols, types, structures and paradigms. Distinguish exact, approximate and absent equivalents.
6. Token-level pedagogy: clicking fn, identifier, parameters, i32, arrow, braces and expression in Rust explains each.
7. Separate compatibility, syntax validation, semantic validation and security status; show why unsupported.
8. Dark navy, cyan and violet branding; approved infinity code logo; no Made in Argentina label.
9. Local AI optional; deterministic mode must remain usable.
10. Never silently replace educational explanations with generated snippets.
11. Compare CSS native, JavaScript DOM, React component and Python/Flask indirect HTML/CSS for page background; explain C/C++ and Rust limitations.
12. Explain scope differences: a React div is not the document body.
